# 오늘, 공유함

오늘 할 일도, 오늘 해낸 일도. 친구와 나누고 서로 응원하는 루틴 플래너입니다.

## 어떻게 쓰나요?

1. 앱을 열면 평소 루틴이 오늘 목록에 준비됩니다. 시험이나 발표가 있는 날에는 다른 템플릿으로 바꿀 수 있어요.
2. 할 일을 체크하고, 이어서 볼 내용은 개인 메모에 남겨요.
3. 친구에게 보여 주고 싶은 계획과 성과만 골라 마을 광장에 올려요.
4. 서로 응원하고, 이번 주에 완료한 일과 함께 나눈 성과를 돌아봐요.

## 개발 현황

첫 멀티계정 파일럿을 준비하는 단계입니다. 브라우저 체험판에서 오늘 루틴 체크, 선택 공유, 예시 친구의 응원과 주간 기록 흐름을 확인했습니다. 다음 개발 목표는 초대받은 두 사람이 서로 다른 브라우저에서 같은 게시물을 확인하고 응원하는 것입니다.
