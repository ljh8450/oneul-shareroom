# 초기 개발 기획안

**오늘, 공유함**은 매일의 루틴을 바로 시작하고, 고른 계획과 성과를 초대받은 친구들과 나누는 플래너입니다.

## 해결할 문제

공부·과제·프로젝트를 병행하면 매일 비슷한 계획을 다시 적느라 시작이 늦어지고, 지난번에 어디까지 했는지 다시 찾아야 합니다. 친구에게 오늘의 계획이나 성과를 알려 주려면 한 번 더 정리해야 합니다.

첫 사용자는 하루를 불규칙하게 시작하는 사람과 그 친구 3~5명입니다. 친구들은 각자의 시간에 들어와 계획을 확인하고 응원할 수 있습니다.

## 첫 버전에서 만들 경험

| 경험 | 구현 방향 | 확인할 가설 |
| --- | --- | --- |
| 오늘 시작 | 기본 루틴으로 오늘 목록을 준비하고 최근 개인 메모를 볼 수 있게 합니다. | 전날 준비 없이도 다음에 할 일을 찾을 수 있습니다. |
| 계획 바꾸기 | 시험·면접·프로젝트 같은 날에는 다른 템플릿을 오늘에만 적용합니다. | 하루 일정이 달라져도 평소 루틴을 다시 입력할 필요가 줄어듭니다. |
| 계획·성과 공유 | 목록에서 직접 고른 제목을 마을 광장에 올립니다. 개인 메모는 본인에게만 보입니다. | 공유할 내용을 다시 입력하는 수고가 줄어듭니다. |
| 응원·돌아보기 | 친구의 글에 응원하고, 주간 기록에서 완료한 일과 공유 성과를 봅니다. | 서로 다른 목표를 가진 친구도 다시 방문할 이유가 생깁니다. |

화면은 순서가 있는 체크리스트와 작은 마을 지도를 중심으로 구성합니다. 광장은 지도에서 한 번 눌러 열고, 키보드와 좁은 화면에서도 접근할 수 있게 합니다.

## 개발 순서

| 단계 | 목표 | 확인할 결과 |
| --- | --- | --- |
| S0 · 착수 | 파일럿 정책과 기술 선택 | 인증·데이터·배포, 날짜 경계, 공유·탈퇴 정책의 결정을 기록합니다. |
| S1 · 개인 루틴 | 오늘 계획, 템플릿, 체크와 메모 | 두 날짜와 두 기기에서 저장·전환·메모 분리를 검증합니다. |
| S2 · 친구 마을 | 초대, 선택 공유, 응원, 주간 기록 | 두 계정에서 같은 게시물과 응원 수를 확인하고, 비회원 접근 차단과 중복 요청을 검증합니다. |
| S3 · 파일럿 | 친구 한 마을에서 일주일 사용 | 관찰 기간과 참가자 수, 막힌 흐름, 다음에 바꿀 점을 기록합니다. |

파일럿에서는 전날 준비 없이 체크를 시작한 사람, 친구에게 응원을 받은 사람, 하루 이상 쉬었다 돌아온 사람을 확인합니다. 사용 행동과 참여자의 설명을 함께 보고 다음에 개발할 기능의 우선순위를 조정합니다.

## 데일리 개발 기록

- 한국 시간 기준으로 개발한 날짜마다 [기록 양식](daily/TEMPLATE.md)을 복사합니다. 파일명과 제목은 `yy-dd-mm`입니다. 예를 들어 2026년 11월 23일 기록은 `26-23-11.md`로 작성하고 제목은 `26-23-11`로 씁니다.
- 하루 동안 확인한 변경, 피드백과 근거, 바뀐 결정, 다음에 검증할 일을 짧게 적습니다. 테스트는 통과·실패·미실행을 구분하고, 실행한 환경이나 확인할 수 있는 근거를 남깁니다.
- 새 글을 작성하면 아래 목록에 최신순으로 연결합니다. 실제 이슈·PR·커밋이 있을 때 함께 링크합니다.
